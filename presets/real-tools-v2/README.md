# Preset ตามเอกสารองค์ประกอบ 30 ตุลาคม 2569

รุ่น real-tools-2026-10-30-v8 — คำถามเลือกตอบทีละข้อ 4 มิติ ไม่มี AI สร้างข้อความสด

- ทั้งหมด 625 ชุดคำตอบ จับคู่ได้ 176 ชุด และยังไม่มีไฟล์ที่ตรง 449 ชุด
- 10 แพ็กเกจตามพื้นที่และเป้าหมาย 15 รูปแบบชุดไฟล์
- ใช้เครื่องมือหลัก 18 ชิ้นและต้นฉบับ 30 ไฟล์เดิม เครื่องมือเสริม 21 ชิ้นยังไม่รวมในผลลัพธ์เพราะยังไม่มีไฟล์
- เป้าหมาย 3–5 ชิ้นใช้เมื่อมีไฟล์ที่ตรงจริง บางเส้นทางได้ 1–2 ชิ้น ไม่เติมเอกสารองค์ประกอบหรือไฟล์สมมติ
- ขั้นตอน วิธีทำ เป้าหมาย และแท็กคำแนะนำสรุปจากเอกสารองค์ประกอบทั้ง 5 พร้อมเลขหน้าอ้างอิง ไม่มีการวนคำแนะนำ 20 ชุด และไม่อ้างว่าได้รับการรับรองวิชาการใหม่
- กลุ่มปฐมวัยรวม 0–6 ปี แต่สื่อจริงไม่ครอบคลุมทุกวัย ต้องตรวจช่วงวัยก่อนใช้ เด็ก 0–2 ปีไม่ใช้โดยอัตโนมัติ
- บทบาท อสม./บุคลากร รพ.สต. รวมหลายวิชาชีพ แผนบริการจึงระบุให้ผู้มีใบประกอบวิชาชีพใช้แนวทางคลินิก อสม. ทำหน้าที่ประสาน

หน้าแชตบอตกรองคำตอบตามเส้นทางที่มีปลายทางจริงทั้ง 176 ชุด ส่วน 449 ชุดที่ยังไม่มีไฟล์เก็บใน all-paths.csv เพื่อวางแผนเติมคลัง ไม่แสดงเป็นตัวเลือกในแชตบอต

ดู presets.csv สำหรับเส้นทางที่จัดแพ็กเกจได้ และ guidance-tags.csv สำหรับแท็กพร้อมที่มา

สร้างใหม่: node scripts/build-intervention-presets.mjs
นำเข้า: node --env-file=.env.local scripts/release-real-tools.mjs --stage --preset=presets/real-tools-v2/presets.json
