# ตัวอย่างบทสนทนาและแผนรุ่น 7

## ชุดร่วมกำหนดนโยบายและจัดทีมสถานศึกษา

1. คุณจะนำชุดเครื่องมือไปใช้ในพื้นที่ไหน?
   - สถานศึกษา (โรงเรียน / วิทยาลัย / มหาวิทยาลัย)
2. คุณจะร่วมขับเคลื่อนงานนี้ในบทบาทไหน?
   - ครู / บุคลากรทางการศึกษา / ผู้บริหารโรงเรียน
3. กลุ่มเด็กและเยาวชนที่คุณดูแลคือกลุ่มไหน?
   - เด็กปฐมวัย / ศพด. (0–6 ปี)
4. คุณอยากให้เกิดความเปลี่ยนแปลงเรื่องไหนเป็นหลัก?
   - กำหนดนโยบายและระบบบริหารงานควบคุมบุหรี่ไฟฟ้า

คุณคือ ครู / บุคลากรทางการศึกษา / ผู้บริหารโรงเรียน ที่ดำเนินงานใน สถานศึกษา (โรงเรียน / วิทยาลัย / มหาวิทยาลัย) เพื่อดูแลกลุ่ม เด็กปฐมวัย / ศพด. (0–6 ปี) โดยมีเป้าหมายหลักคือ กำหนดนโยบายและระบบบริหารงานควบคุมบุหรี่ไฟฟ้า

เครื่องมือ: 7 มาตรการโรงเรียนปลอดบุหรี่

1. **เตรียมทีมและทบทวนบริบท** — ให้ครูหรือผู้ดูแลทบทวนช่วงวัยในต้นฉบับ เลือกกิจกรรมสำหรับวัยที่เอกสารรองรับ และไม่ใช้สื่อชุดนี้กับเด็ก 0–2 ปีโดยอัตโนมัติ
2. **ร่วมกำหนดและสื่อสารข้อตกลง** — ให้ทีมและผู้เรียนร่วมเสนอแนวทาง แล้วเลือกวิธีสื่อสารนโยบายที่ทุกฝ่ายเข้าใจ
3. **ทบทวนการทำงานร่วมกัน** — กลับมาใช้ส่วนระบบบริหารในคู่มือ ทบทวนหน้าที่และสิ่งที่ต้องปรับร่วมกับทีม

**ปัจจัยความสำเร็จ**
- ผู้บริหารประกาศเจตนารมณ์ชัดเจน และสนับสนุนทรัพยากร
- เปิดให้เยาวชนและแกนนำร่วมวางแผนและขับเคลื่อนกิจกรรม
- ใช้การรับฟังและดูแลช่วยเหลือแทนการลงโทษ

**ข้อควรระวัง**
- รักษาความลับ ไม่ประจานหรือตีตราเด็กและเยาวชน
- หลีกเลี่ยงการใช้ความกลัว เน้นความเข้าใจและเหตุผล
- ไม่ใช้การลงโทษรุนแรงหรือการให้ออกเป็นทางเลือกแรก

**มาตรฐานความสำเร็จ**
- มีข้อตกลงและผู้รับผิดชอบงานที่ชัดเจน
- มีการทบทวนการทำงานเพื่อดูแลพื้นที่ปลอดบุหรี่ไฟฟ้า

## ชุดออกแบบบทเรียนและกิจกรรมรู้เท่าทันบุหรี่ไฟฟ้า

1. คุณจะนำชุดเครื่องมือไปใช้ในพื้นที่ไหน?
   - สถานศึกษา (โรงเรียน / วิทยาลัย / มหาวิทยาลัย)
2. คุณจะร่วมขับเคลื่อนงานนี้ในบทบาทไหน?
   - ครู / บุคลากรทางการศึกษา / ผู้บริหารโรงเรียน
3. กลุ่มเด็กและเยาวชนที่คุณดูแลคือกลุ่มไหน?

4. คุณอยากให้เกิดความเปลี่ยนแปลงเรื่องไหนเป็นหลัก?
   - บูรณาการในวิชาสอนและกิจกรรมนอกหลักสูตร

คุณคือ ครู / บุคลากรทางการศึกษา / ผู้บริหารโรงเรียน ที่ดำเนินงานใน สถานศึกษา (โรงเรียน / วิทยาลัย / มหาวิทยาลัย) เพื่อดูแลกลุ่ม เด็กปฐมวัย / ศพด. (0–6 ปี) โดยมีเป้าหมายหลักคือ บูรณาการในวิชาสอนและกิจกรรมนอกหลักสูตร

เครื่องมือ: แผนการเรียนรู้สำหรับครู ศพด. → ชุดสื่อเรียนรู้สำหรับปฐมวัย → นิทานเด็กปลอดพอต

1. **เตรียมกิจกรรมและประเมินการเรียนรู้** — ให้ครูหรือผู้ดูแลทบทวนช่วงวัยในต้นฉบับ เลือกกิจกรรมสำหรับวัยที่เอกสารรองรับ และไม่ใช้สื่อชุดนี้กับเด็ก 0–2 ปีโดยอัตโนมัติ
2. **สร้างการเรียนรู้ผ่านกิจกรรม** — ใช้สื่อหรือกิจกรรมในชุดเครื่องมือ เปิดโอกาสให้ผู้เรียนตั้งคำถามและแลกเปลี่ยนสิ่งที่เข้าใจ
3. **ทบทวนผลและปรับกิจกรรม** — ใช้คำถามหรือแบบประเมินตามวิธีในต้นฉบับ แล้วนำผลภาพรวมมาปรับการเรียนรู้ครั้งต่อไป

**ปัจจัยความสำเร็จ**
- ผู้บริหารประกาศเจตนารมณ์ชัดเจน และสนับสนุนทรัพยากร
- เปิดให้เยาวชนและแกนนำร่วมวางแผนและขับเคลื่อนกิจกรรม
- ใช้การรับฟังและดูแลช่วยเหลือแทนการลงโทษ

**ข้อควรระวัง**
- รักษาความลับ ไม่ประจานหรือตีตราเด็กและเยาวชน
- หลีกเลี่ยงการใช้ความกลัว เน้นความเข้าใจและเหตุผล
- ไม่ใช้การลงโทษรุนแรงหรือการให้ออกเป็นทางเลือกแรก

**มาตรฐานความสำเร็จ**
- มีกิจกรรมการเรียนรู้ที่เลือกให้ตรงกับวัย
- มีการทบทวนผลเพื่อนำไปปรับกิจกรรม

## ชุดเชื่อมสถานศึกษา บ้าน และชุมชนให้เป็นพื้นที่ปลอดภัย

1. คุณจะนำชุดเครื่องมือไปใช้ในพื้นที่ไหน?
   - สถานศึกษา (โรงเรียน / วิทยาลัย / มหาวิทยาลัย)
2. คุณจะร่วมขับเคลื่อนงานนี้ในบทบาทไหน?
   - ครู / บุคลากรทางการศึกษา / ผู้บริหารโรงเรียน

4. คุณอยากให้เกิดความเปลี่ยนแปลงเรื่องไหนเป็นหลัก?
   - สร้างสภาพแวดล้อมปลอดบุหรี่ไฟฟ้า

1. **เตรียมผู้รับผิดชอบและเลือกงานพื้นที่** — ให้ครูหรือผู้ดูแลทบทวนช่วงวัยในต้นฉบับ เลือกกิจกรรมสำหรับวัยที่เอกสารรองรับ และไม่ใช้สื่อชุดนี้กับเด็ก 0–2 ปีโดยอัตโนมัติ

3. **ติดตามและปรับข้อตกลง** — พูดคุยสิ่งที่ลองทำและแรงสนับสนุนที่ต้องการ แล้วกลับมาปรับงานตามแนวทางในคู่มือ

## ชุดเสริมพลังแกนนำและกิจกรรมที่เยาวชนร่วมออกแบบ

1. คุณจะนำชุดเครื่องมือไปใช้ในพื้นที่ไหน?
   - สถานศึกษา (โรงเรียน / วิทยาลัย / มหาวิทยาลัย)
2. คุณจะร่วมขับเคลื่อนงานนี้ในบทบาทไหน?
   - ครู / บุคลากรทางการศึกษา / ผู้บริหารโรงเรียน
3. กลุ่มเด็กและเยาวชนที่คุณดูแลคือกลุ่มไหน?
   - ระดับประถมศึกษา (ป.1–ป.6)
4. คุณอยากให้เกิดความเปลี่ยนแปลงเรื่องไหนเป็นหลัก?
   - เสริมพลังและการมีส่วนร่วมของเยาวชน

คุณคือ ครู / บุคลากรทางการศึกษา / ผู้บริหารโรงเรียน ที่ดำเนินงานใน สถานศึกษา (โรงเรียน / วิทยาลัย / มหาวิทยาลัย) เพื่อดูแลกลุ่ม ระดับประถมศึกษา (ป.1–ป.6) โดยมีเป้าหมายหลักคือ เสริมพลังและการมีส่วนร่วมของเยาวชน

เครื่องมือ: 7 มาตรการโรงเรียนปลอดบุหรี่ → คู่มือสื่อและกิจกรรมรู้เท่าทัน → ชุดกิจกรรมเรียนรู้ 7+1

1. **ชวนเยาวชนร่วมวางแผน** — ใช้ส่วนการมีส่วนร่วมในคู่มือ ให้แกนนำเสนอสิ่งที่อยากปรับร่วมกับผู้ดูแลกิจกรรม
2. **ร่วมออกแบบสื่อและกิจกรรม** — ให้เยาวชนเลือกกิจกรรมจากชุดสื่อ ฝึกตรวจข้อมูล และออกแบบวิธีสื่อสารร่วมกัน
3. **แลกเปลี่ยนผลและส่งต่องาน** — ให้กลุ่มทบทวนสิ่งที่เรียนรู้ สรุปสิ่งที่จะปรับ และตกลงผู้รับช่วงกิจกรรมต่อ

**ปัจจัยความสำเร็จ**
- ผู้บริหารประกาศเจตนารมณ์ชัดเจน และสนับสนุนทรัพยากร
- เปิดให้เยาวชนและแกนนำร่วมวางแผนและขับเคลื่อนกิจกรรม
- ใช้การรับฟังและดูแลช่วยเหลือแทนการลงโทษ

**ข้อควรระวัง**
- รักษาความลับ ไม่ประจานหรือตีตราเด็กและเยาวชน
- หลีกเลี่ยงการใช้ความกลัว เน้นความเข้าใจและเหตุผล
- ไม่ใช้การลงโทษรุนแรงหรือการให้ออกเป็นทางเลือกแรก

**มาตรฐานความสำเร็จ**
- เยาวชนมีส่วนร่วมออกแบบและตัดสินใจในกิจกรรม
- มีข้อเรียนรู้และผู้รับช่วงงานต่อ

## ชุดประสานสถานศึกษาและครอบครัวเพื่อช่วยเหลือผู้เรียน

1. คุณจะนำชุดเครื่องมือไปใช้ในพื้นที่ไหน?
   - สถานศึกษา (โรงเรียน / วิทยาลัย / มหาวิทยาลัย)
2. คุณจะร่วมขับเคลื่อนงานนี้ในบทบาทไหน?
   - ครู / บุคลากรทางการศึกษา / ผู้บริหารโรงเรียน
3. กลุ่มเด็กและเยาวชนที่คุณดูแลคือกลุ่มไหน?
   - ระดับมัธยมศึกษา / อาชีวศึกษา (ม.1–ม.6 / ปวช.–ปวส.)
4. คุณอยากให้เกิดความเปลี่ยนแปลงเรื่องไหนเป็นหลัก?
   - ดูแลช่วยเหลือให้ลด ละ เลิกบุหรี่และบุหรี่ไฟฟ้า

คุณคือ ครู / บุคลากรทางการศึกษา / ผู้บริหารโรงเรียน ที่ดำเนินงานใน สถานศึกษา (โรงเรียน / วิทยาลัย / มหาวิทยาลัย) เพื่อดูแลกลุ่ม ระดับมัธยมศึกษา / อาชีวศึกษา (ม.1–ม.6 / ปวช.–ปวส.) โดยมีเป้าหมายหลักคือ ดูแลช่วยเหลือให้ลด ละ เลิกบุหรี่และบุหรี่ไฟฟ้า

เครื่องมือ: 7 มาตรการโรงเรียนปลอดบุหรี่ → คู่มือสื่อสารเชิงบวกในครอบครัว

1. **จัดทีมและช่องทางรับฟัง** — ทบทวนส่วนระบบช่วยเหลือในคู่มือ กำหนดผู้รับเรื่องและช่องทางพูดคุยเป็นส่วนตัว
2. **ประสานผู้ดูแลและบริการ** — ใช้แนวทางสื่อสารและส่งต่อตามขอบเขตของคู่มือ ประสานผู้รับผิดชอบที่เหมาะกับความช่วยเหลือที่ต้องการ
3. **ติดตามความต่อเนื่อง** — ตกลงวิธีติดตามกับผู้เกี่ยวข้อง โดยรักษาความลับและแยกข้อมูลรายบุคคลจากรายงานภาพรวม

**ปัจจัยความสำเร็จ**
- ผู้บริหารประกาศเจตนารมณ์ชัดเจน และสนับสนุนทรัพยากร
- เปิดให้เยาวชนและแกนนำร่วมวางแผนและขับเคลื่อนกิจกรรม
- ใช้การรับฟังและดูแลช่วยเหลือแทนการลงโทษ

**ข้อควรระวัง**
- รักษาความลับ ไม่ประจานหรือตีตราเด็กและเยาวชน
- หลีกเลี่ยงการใช้ความกลัว เน้นความเข้าใจและเหตุผล
- ไม่ใช้การลงโทษรุนแรงหรือการให้ออกเป็นทางเลือกแรก
- การประเมินและรักษาเป็นหน้าที่ของบุคลากรวิชาชีพ ผู้ประสานใช้ช่องทางส่งต่อตามคู่มือ

- ติดตามการช่วยเหลือโดยรักษาความลับของผู้รับบริการ

เครื่องมือ: แนวทางเฝ้าระวังและส่งต่อภาวะปอดอักเสบ → แนวทางบำบัดภาวะติดนิโคติน

1. **เตรียมทีมวิชาชีพและช่องทางส่งต่อ** — ให้บุคลากรวิชาชีพทบทวนแนวทางเฝ้าระวังต้นฉบับ ส่วน อสม. ประสานช่องทางรับเรื่องและส่งต่อ
2. **ประสานบริการช่วยเลิก** — ให้ผู้ประกอบวิชาชีพใช้แนวทางบำบัดภาวะติดนิโคตินตามขอบเขตงาน อสม. และผู้ประสานไม่วินิจฉัยหรือแนะนำยาเอง
3. **ติดตามความต่อเนื่อง** — ตกลงวิธีติดตามกับผู้เกี่ยวข้อง โดยรักษาความลับและแยกข้อมูลรายบุคคลจากรายงานภาพรวม

**ปัจจัยความสำเร็จ**
- กำหนดผู้รับผิดชอบและการสนับสนุนให้ชัดเจน
- ใช้กระบวนการมีส่วนร่วมของผู้เกี่ยวข้อง
- ใช้การรับฟังและดูแลช่วยเหลือ

**ข้อควรระวัง**
- รักษาความลับ ไม่ประจานหรือตีตราเด็กและเยาวชน
- หลีกเลี่ยงการใช้ความกลัว เน้นความเข้าใจและเหตุผล
- การประเมินและรักษาเป็นหน้าที่ของบุคลากรวิชาชีพ ผู้ประสานใช้ช่องทางส่งต่อตามคู่มือ

**มาตรฐานความสำเร็จ**
- มีผู้รับผิดชอบและช่องทางดูแลหรือส่งต่อที่ชัดเจน
- ติดตามการช่วยเหลือโดยรักษาความลับของผู้รับบริการ
