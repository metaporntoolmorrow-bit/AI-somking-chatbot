# ตัวอย่างบทสนทนาและแพ็กเกจที่ใช้ต่อได้

## สถานศึกษา

**ผู้ช่วย:** คุณอยากเริ่มดูแลปัญหาบุหรี่ไฟฟ้าในพื้นที่ไหน?

**คุณ:** สถานศึกษา

**ผู้ช่วย:** คุณจะร่วมดูแลพื้นที่นี้ในบทบาทไหน?

**คุณ:** ผู้บริหารสถานศึกษา

**ผู้ช่วย:** เรื่องไหนที่คุณอยากเริ่มทำให้เป็นระบบ?

**คุณ:** อยากชวนทีมกำหนดนโยบายและแบ่งหน้าที่ให้ชัด

**ผู้ช่วย:** คุณอยากเริ่มทำงานกับกลุ่มไหนบ้าง?

**คุณ:** เด็กปฐมวัย อายุประมาณ 3–6 ปี

**ชุดที่ได้รับ:** ชุดร่วมกำหนดนโยบายและจัดทีมสถานศึกษา

1. **แนวทางจัดนโยบายและทีมงาน** — อ่านขั้นตอนศึกษาบริบท แล้วตกลงทีมงาน ข้อมูลที่จำเป็น และเสียงของผู้เรียนที่จะรับฟัง
2. **7 มาตรการโรงเรียนปลอดบุหรี่** — ใช้ส่วนการกำหนดนโยบาย เปิดให้ครู ผู้เรียน และผู้ปกครองร่วมเสนอแนวทาง
3. **แนวทางจัดนโยบายและทีมงาน** — กำหนดคนประสาน งานที่ต้องทำ ช่องทางช่วยเหลือ และหลักฐานที่จะทบทวน
4. **7 มาตรการโรงเรียนปลอดบุหรี่** — เลือกส่วนสื่อสารนโยบายและระบบช่วยเหลือ ให้ทุกฝ่ายเข้าใจวิธีทำงานร่วมกัน
5. **แนวทางจัดนโยบายและทีมงาน** — ดูการรับรู้นโยบาย การทำงานจริง และเสียงสะท้อน โดยสรุปข้อมูลเป็นภาพรวม

**ข้อควรระวัง:** เข้าร่วมโดยสมัครใจ ไม่ตีตรา และไม่ใช้กิจกรรมแทนการรักษา

## ครอบครัว

**ผู้ช่วย:** คุณอยากเริ่มดูแลปัญหาบุหรี่ไฟฟ้าในพื้นที่ไหน?

**คุณ:** ครอบครัว

**ผู้ช่วย:** คุณจะร่วมดูแลพื้นที่นี้ในบทบาทไหน?

**คุณ:** ผู้ปกครอง

**ผู้ช่วย:** เรื่องไหนที่คุณอยากเริ่มทำให้เป็นระบบ?

**คุณ:** อยากเริ่มคุยและดูแลคนในบ้านไปด้วยกัน

**ผู้ช่วย:** คุณอยากเริ่มทำงานกับกลุ่มไหนบ้าง?

**คุณ:** เด็กปฐมวัย อายุประมาณ 3–6 ปี

**ชุดที่ได้รับ:** ชุดคุยกันและสร้างข้อตกลงบ้านปลอดบุหรี่

1. **คู่มือสื่อสารเชิงบวกในครอบครัว** — เลือกแนวทางสื่อสารเชิงบวก คุยสิ่งที่แต่ละคนห่วงและพร้อมทำ
2. **คู่มือห้องเรียนครอบครัวปลอดบุหรี่** — ใช้กิจกรรมครอบครัวที่ตรงกับวัยและความพร้อม ไม่กดดันให้เล่าเรื่องส่วนตัว
3. **ชุดสื่อเรียนรู้สำหรับปฐมวัย** — เปิดชุดสื่อจากลิงก์ในเอกสาร แล้วเลือกชิ้นที่เหมาะกับเด็ก
4. **นิทานเด็กปลอดพอต** — อ่านนิทานร่วมกัน เปิดโอกาสให้เด็กเล่าสิ่งที่เข้าใจ
5. **แนวทางเชื่อมพื้นที่ บ้าน และชุมชน** — อ่านเฉพาะส่วนบ้านและครอบครัว เลือกสิ่งที่ทำได้ร่วมกัน ไม่ผลักให้เด็กควบคุมผู้ใหญ่
6. **คู่มือสื่อสารเชิงบวกในครอบครัว** — ถามสิ่งที่ลองทำและสิ่งที่ต้องการแรงสนับสนุน แล้วปรับข้อตกลง

**ข้อควรระวัง:** เข้าร่วมโดยสมัครใจ ไม่ตีตรา และไม่ใช้กิจกรรมแทนการรักษา

## ชุมชน

**ผู้ช่วย:** คุณอยากเริ่มดูแลปัญหาบุหรี่ไฟฟ้าในพื้นที่ไหน?

**คุณ:** ชุมชน

**ผู้ช่วย:** คุณจะร่วมดูแลพื้นที่นี้ในบทบาทไหน?

**คุณ:** ผู้รับผิดชอบงานของ อปท.

**ผู้ช่วย:** เรื่องไหนที่คุณอยากเริ่มทำให้เป็นระบบ?

**คุณ:** อยากเชื่อมชุมชน ครอบครัว และท้องถิ่นให้ทำงานร่วมกัน

**ผู้ช่วย:** คุณอยากเริ่มทำงานกับกลุ่มไหนบ้าง?

**คุณ:** ประชาชนในชุมชน

**ชุดที่ได้รับ:** ชุดชุมชนและครอบครัวร่วมดูแลพื้นที่ปลอดบุหรี่

1. **8 วิธีขับเคลื่อน อปท.ปลอดบุหรี่** — ใช้คู่มือท้องถิ่นเลือกงาน ผู้ร่วมดำเนินการ และผู้ประสานบริการ
2. **แนวทางเชื่อมพื้นที่ บ้าน และชุมชน** — เลือกส่วนเครือข่ายชุมชนร่วมกับภาคี กำหนดผู้ใหญ่รับผิดชอบและช่องทางประสาน
3. **คู่มือห้องเรียนครอบครัวปลอดบุหรี่** — เลือกกิจกรรมครอบครัวให้เป็นส่วนหนึ่งของงานชุมชน โดยมีผู้จัดวงดูแล
4. **คู่มือสื่อสารเชิงบวกในครอบครัว** — ใช้การสื่อสารเชิงบวก ให้ครอบครัวเลือกสิ่งที่พร้อมทำโดยไม่ตีตรา
5. **8 วิธีขับเคลื่อน อปท.ปลอดบุหรี่** — ทบทวนงานตามคู่มือท้องถิ่นและประสานหน่วยบริการเมื่อมีผู้ขอความช่วยเหลือ

**ข้อควรระวัง:** เข้าร่วมโดยสมัครใจ ไม่ตีตรา และไม่ใช้กิจกรรมแทนการรักษา

## ระบบบริการสุขภาพ

**ผู้ช่วย:** คุณอยากเริ่มดูแลปัญหาบุหรี่ไฟฟ้าในพื้นที่ไหน?

**คุณ:** ระบบบริการสุขภาพ

**ผู้ช่วย:** คุณจะร่วมดูแลพื้นที่นี้ในบทบาทไหน?

**คุณ:** แพทย์

**ผู้ช่วย:** เรื่องไหนที่คุณอยากเริ่มทำให้เป็นระบบ?

**คุณ:** อยากเชื่อมงานเฝ้าระวัง ส่งต่อ และบริการช่วยเลิก

**ผู้ช่วย:** คุณอยากเริ่มทำงานกับกลุ่มไหนบ้าง?

**คุณ:** ผู้รับบริการวัยผู้ใหญ่ที่ใช้บุหรี่หรือบุหรี่ไฟฟ้า

**ชุดที่ได้รับ:** ชุดจัดระบบเฝ้าระวัง ส่งต่อ และบริการช่วยเลิก

1. **แนวทางเฝ้าระวังและส่งต่อภาวะปอดอักเสบ** — ทีมวิชาชีพทบทวนแนวทางต้นฉบับและตกลงช่องทางประสานเมื่อจำเป็นต้องประเมินหรือส่งต่อ
2. **แนวทางบำบัดภาวะติดนิโคติน** — ทบทวนหัวข้อที่ตรงกับผู้รับบริการ และกำหนดผู้รับผิดชอบตามขอบเขตวิชาชีพ
3. **แนวทางบำบัดภาวะติดนิโคติน** — ใช้แนวทางต้นฉบับทบทวนการนัดหมาย ติดตาม และประสานงานของทีม

**ข้อควรระวัง:** ใช้คู่มือต้นฉบับตามขอบเขตวิชาชีพ ไม่ใช้ลำดับนี้แทนคำสั่งวินิจฉัยหรือรักษา

## สถานประกอบการ

**ผู้ช่วย:** คุณอยากเริ่มดูแลปัญหาบุหรี่ไฟฟ้าในพื้นที่ไหน?

**คุณ:** สถานประกอบการ

**ผู้ช่วย:** คุณจะร่วมดูแลพื้นที่นี้ในบทบาทไหน?

**คุณ:** ผู้บริหาร / เจ้าของสถานประกอบการ

**ผู้ช่วย:** เรื่องไหนที่คุณอยากเริ่มทำให้เป็นระบบ?

**คุณ:** อยากให้ผู้บริหารและทีมงานร่วมจัดระบบที่ทำงานปลอดบุหรี่

**ผู้ช่วย:** คุณอยากเริ่มทำงานกับกลุ่มไหนบ้าง?

**คุณ:** พนักงาน / คนวัยทำงานในสถานประกอบการ

**ชุดที่ได้รับ:** ชุดขับเคลื่อนที่ทำงานปลอดบุหรี่ทั้งองค์กร

1. **คู่มือผู้บริหารสถานประกอบการ** — ใช้คู่มือผู้บริหารคุยเป้าหมาย ผู้รับผิดชอบ และทรัพยากรที่จะสนับสนุน
2. **คู่มือคณะทำงานสถานประกอบการ** — เลือกกระบวนการในคู่มือคณะทำงาน แบ่งหน้าที่ให้เชื่อมกับงานจริง
3. **แนวทางองค์กรปลอดบุหรี่** — ใช้กรอบองค์กรปลอดบุหรี่ดูนโยบาย พื้นที่ และการมีส่วนร่วมให้เชื่อมกัน
4. **คู่มือคณะทำงานสถานประกอบการ** — นำประเด็นที่พบมาปรับงานของทีมและการประสานบริการช่วยเลิก

**ข้อควรระวัง:** เข้าร่วมโดยสมัครใจ ไม่ตีตรา และไม่ใช้กิจกรรมแทนการรักษา
