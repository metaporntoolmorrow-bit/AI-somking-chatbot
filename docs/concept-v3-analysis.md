## จุดที่ต้องแยกให้ถูก

- สไลด์คอนเซปต์แบ่ง 39 รายการเป็นหลัก 19 + เสริม 20 แต่ tracker ที่ใช้ปัจจุบันแบ่งหลัก 18 + เสริม 21 และเลขรายเครื่องมือไม่ตรงกัน จึงเทียบด้วยชื่อและไฟล์จริง ไม่ย้ายเลขจากสไลด์มาแทนรหัสในเว็บ
- เครื่องมือหลัก 18 ชิ้นยังเป็นชุดเดิม เพิ่มเอกสารแนวทางองค์ประกอบที่มีจริง 4 ฉบับเป็นหมวดแนวทางประกอบ ไม่เรียกว่าเครื่องมือหลักเพิ่มอีก 4 ชิ้น
- ยังไม่มีไฟล์องค์ประกอบที่ 5 แยกฉบับ จึงไม่สร้างเอกสารขึ้นมาแทน ใช้กรอบในคอนเซปต์/โครงร่างร่วมกับคู่มือสถานศึกษาและการสื่อสารกับครอบครัว ส่วนงานคลินิกใช้เครื่องมือ 17–18 เฉพาะบทบาทบริการสุขภาพ
- ยังไม่มีคู่มืออุดมศึกษาเฉพาะที่ tracker กล่าวถึง เส้นทางอุดมศึกษาระบุการปรับใช้ร่วมกับทีมอุดมศึกษาและไม่อ้างว่าเป็นแนวทางเฉพาะที่มีไฟล์พร้อม
- ไม่เพิ่มเครื่องมือเสริม 21 ชิ้นเข้าเส้นทางดาวน์โหลดหากยังไม่มีไฟล์จริง

## คำถามและคำตอบ

คงข้อมูลจับคู่ 5 ด้าน ได้แก่ พื้นที่ บทบาท เรื่องที่เริ่มทำ สถานการณ์ป้องกัน/ช่วยเหลือ และกลุ่มเป้าหมาย ปรับภาษาคำถามให้บอกงานที่จะทำและใช้คำถามเรื่องเป้าหมายเป็นจุดเลือกองค์ประกอบ

1. คุณอยากเริ่มดูแลปัญหาบุหรี่ไฟฟ้าในพื้นที่ไหน?
2. คุณจะร่วมดูแลพื้นที่นี้ในบทบาทไหน?
3. เรื่องไหนที่คุณอยากเริ่มทำให้เป็นระบบ?
4. อยากเน้นป้องกันการเริ่มใช้ หรือช่วยคนที่เริ่มใช้แล้ว? แสดงเมื่อมีหลายทางเลือกที่ตรงจริง หากเหลือทางเดียวจะกำหนดให้อัตโนมัติ
5. คุณอยากเริ่มทำงานกับกลุ่มไหนบ้าง? เลือกหลายข้อได้และยืนยันเฉพาะข้อนี้

ตัวเลือกทุกข้อกรองจากเส้นทางที่มีจริง กลุ่มปฐมวัยและประถมต้นใช้ผู้ใหญ่เป็นผู้จัดกิจกรรม ไม่เปิดบทบาทแกนนำเด็กให้รับผิดชอบงานตรวจค้น/ช่วยเหลือเชิงวิชาชีพ แบบสำรวจประถมและมัธยมไม่ข้ามกลุ่มวัย รายงานเยาวชนชาติพันธุ์เป็นข้อมูลอ้างอิง ไม่แทนแบบประเมินเปล่า

## แพ็กเกจสถานศึกษาตาม 5 องค์ประกอบ

| จุดเริ่มต้น | ชุดเครื่องมือและแนวทาง | สิ่งที่ทำต่อกัน |
|---|---|---|
| นโยบายและระบบงาน | แนวทางองค์ประกอบ 1 + 7 มาตรการโรงเรียนปลอดบุหรี่ | ดูบริบทและตั้งทีม → ร่วมนโยบาย → แบ่งหน้าที่ → สื่อสาร/ช่วยเหลือ → ทบทวน |
| การเรียนรู้ | แนวทางองค์ประกอบ 2 + สื่อ กิจกรรม และแบบสำรวจตามวัย | เตรียมเป้าหมาย → สำรวจก่อนเรียนรู้เมื่อมีแบบตรงวัย → ลงมือ → ทบทวน → ปรับการสอน |
| สภาพแวดล้อม | แนวทางองค์ประกอบ 3 + คู่มือสถานศึกษา + การสื่อสารในครอบครัว | สำรวจพื้นที่ → ข้อตกลง → คุยกับบ้าน → ประสานชุมชน → ทบทวน |
| การมีส่วนร่วมเยาวชน | แนวทางองค์ประกอบ 4 + คู่มือสถานศึกษา + สื่อและกิจกรรม | ตั้งแกนนำ/ครูพี่เลี้ยง → ร่วมตัดสินใจ → สร้างกิจกรรม → ลงมืออย่างปลอดภัย → ส่งต่อรุ่นถัดไป |
| ดูแลช่วยเหลือ | คู่มือสถานศึกษา + สื่อสารเชิงบวกในครอบครัว | ผู้รับเรื่อง → รับฟังเป็นส่วนตัว → ประสานวิชาชีพ → ติดตามอย่างรักษาความลับ |

ครอบครัวและชุมชนใช้แนวทางองค์ประกอบ 3 เฉพาะส่วนที่ตรงบริบทประกอบกับเครื่องมือเดิม ที่ทำงานใช้คู่มือสถานประกอบการเดิม และบริการสุขภาพใช้คู่มือวิชาชีพเดิม การเชื่อมข้ามพื้นที่มีเหตุผลระบุใน `collaborationBridges`

การประกอบชุดและการย่อขั้นตอนเป็นการตัดสินใจเชิงออกแบบจากหลักฐานข้างต้น ไม่ใช่ข้อความอ้างตรงหรือการรับรองประสิทธิผลเพิ่มเติม ทุกหัวข้อมีไฟล์ต่างกันอย่างมีเหตุผลและยังเป็นแพ็กเกจหลายเครื่องมือ ไม่เติมไฟล์ที่ไม่เกี่ยวข้องเพื่อให้ดูต่าง

## หน้าผลลัพธ์และการส่งออก

- ตัด “ดูไฟล์ในแพ็กเกจนี้” ออก เหลือทางเปิดเครื่องมือจากลำดับการใช้งานที่มีอยู่แล้ว
- ใช้หน้าตา PDF ตามที่อนุมัติไว้ และตรวจให้จบ A4 แนวนอนหน้าเดียว
- คงคำแนะนำวน 20 ชุด แต่ข้อควรระวังเฉพาะองค์ประกอบ เช่น สิทธิผู้เรียน ความปลอดภัยของแกนนำ และขอบเขตวิชาชีพ จะไม่ถูกวนออก
- ZIP ชื่อ `ชุดเครื่องมือสำหรับคุณ.zip` รวมไฟล์จริงขนาดไม่เกิน 6 MB รวมถึงแนวทางใหม่ 4 ฉบับเมื่อเกี่ยวข้อง ไฟล์ใหญ่ยังเป็นลิงก์ใน TXT
- แนวทางเรียงใช้และข้อความประกอบบนเว็บ PDF และคู่มือเริ่มใช้ใน ZIP ใช้ข้อมูลชุดเดียวกัน

## การเผยแพร่และย้อนกลับ

สร้าง release ใหม่และเส้นทาง `REAL3-*` เพื่อไม่ตีความรหัสเก่าเป็นคนละแผน ตรวจร่างผ่าน `CONTENT_PREVIEW_VERSION` และทดสอบทุกกลุ่มบริบท/ชุดเครื่องมือก่อนสลับ active release เก็บ release เดิมและไฟล์เดิมไว้สำหรับย้อนกลับ ไม่ลบหรือเขียนทับข้อมูลเดิม
