# แดชบอร์ดสำหรับ สสส.

ใช้ต้นแบบฉบับ lean จาก `แดชบอร์ด/2026-10-30/https-ai-somking-chatbot-vercel-app/outputs/tracking-dashboard.html` และ `work/lean-dashboard-shell.html` ไม่ใช้ฉบับ dense ที่ถูกยกเลิก เจ้าของโครงการเลือกให้ **แสดงข้อมูลตัวอย่างจากม็อกอัปก่อน** ในรอบนี้ จึงไม่ติดตั้งระบบเก็บสถิติจริงและไม่ใช้ตัวเลขตัวอย่างปะปนกับ Supabase

## Direction contract

THESIS: ให้ สสส. เห็นภาพรวมว่าตอบคำถามครบและจับคู่ได้เท่าไร แล้วดูความต้องการจากสี่คำตอบอย่างรวดเร็ว คงหน้ากระชับตามต้นแบบ ไม่มี sidebar หรือรายการรายบุคคล

OWN-WORLD: ใช้ขาวบนพื้นเทาอ่อน หัวข้อสีน้ำเงินเข้ม กราฟและอัตราตอบครบสีเขียวอมฟ้า อัตราจับคู่สีส้ม ฟอนต์ Prompt/Sarabun ที่แนบในต้นแบบ

STORY: กดปุ่มแดชบอร์ดสำหรับ สสส. จากหน้าเว็บ → เข้าสู่ระบบด้วย Admin1/Admin2 → ดูตัวเลขตัวอย่าง เปลี่ยนช่วงเวลา สลับกราฟ และส่งออกข้อมูลรวม

FIRST VIEWPORT: หัวเรื่องพร้อมป้ายข้อมูลตัวอย่างและช่วงเวลา ตามด้วย KPI สองช่อง กราฟแท็บสี่คำถาม และตารางห้าบริบท ท้ายหน้ามีที่มาข้อมูลกับทางกลับหน้าเว็บ

FORM: ใช้ต้นแบบ lean ที่ผู้ใช้ให้มาโดยตรง ไม่สุ่มแนวทางใหม่ ตัวเลขและ CSV ต้องคำนวณจากข้อมูลตัวอย่างชุดเดียวกัน

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## ขอบเขตข้อมูลและสิทธิ์

- เส้นทาง `/dashboard` ตรวจ Auth และบทบาท active admin1/admin2 ฝั่ง server ส่วนบัญชีทั่วไปและบัญชีถูกระงับเข้าไม่ได้
- กดจากหน้าแรกหรือ footer แล้วเข้าหน้า login จะกลับแดชบอร์ดหลังล็อกอิน ไม่รับ URL เปลี่ยนปลายทางจากภายนอก
- API ส่งออก CSV ตรวจสิทธิ์ใหม่ทุกครั้งและไม่ cache ข้อมูล ไม่มีการเพิ่มสิทธิ์จัดการสมาชิกให้ Admin2
- ข้อมูลตัวอย่าง 1,248 ครั้ง คง seed และเงื่อนไขต้นแบบ ช่วง 30 วันตอบครบ 984 ครั้ง จับคู่ 912 ครั้ง อัตรา 78.8% / 92.7% ไม่ใช่สถิติของเว็บจริง
- ฐานกราฟและตารางใช้เฉพาะครั้งที่ตอบครบสี่ข้อ ไม่เติมคำตอบที่ขาด ส่งออกทุกบริบทในช่วงที่เลือก ไม่จำกัดแค่ห้าแถวที่แสดง
- ช่วงเวลาตัวอย่างคงวันที่ 1–30 ตุลาคม 2569 และมีตัวเลือก 30/14/7 วัน ไม่มีการอ้างว่าเป็นผลลัพธ์ด้านสุขภาพ
- หน้าอื่น แชตบอต Preset เครื่องมือ PDF/ZIP และผลประเมินจริงใน Supabase คงเดิม

## การทดสอบ

ตรวจค่ากับสคริปต์ตัวอย่างต้นฉบับโดยอิสระ ตรวจตัวกรอง/แท็บ/CSV ที่สอดคล้องกัน การแสดงมือถือ และสิทธิ์ anonymous/user/admin2/suspended โดยใช้บัญชี QA ชั่วคราวที่ไม่ส่งอีเมลและลบหลังตรวจ

ผลในเครื่อง: 3 ช่วงเวลาและ 4 กราฟตรงกับสคริปต์ต้นแบบ CSV ดาวน์โหลดครบ 3 ช่วง ตรวจความกว้าง 1440/690/390/320px ไม่มี page overflow ทั้ง Admin1/Admin2 เข้าได้ ส่วน anonymous/user/suspended เข้าไม่ได้ และ Admin2 เปิดหน้าสมาชิกไม่ได้ ทดสอบ login return path กับ open redirect ผ่าน บัญชี QA ถูกลบหลังตรวจ ภาพและรายงานอยู่ใน `output/qa/dashboard-v1`

ตรวจภาพ desktop/mobile แล้วคงลำดับและสีของต้นแบบ ฟอนต์คัดจากไฟล์ผู้ใช้พร้อม OFL ไม่มี shipping raster ใหม่ กราฟใช้ transform แทนการ animate width และเคารพ reduced motion ตัวส่งออกมีสถานะกำลังเตรียม ลองใหม่เมื่อ 503 และลิงก์เข้าสู่ระบบเมื่อหมดสิทธิ์ ไม่บันทึกไฟล์ error แทน CSV การทดสอบแชตบอตเดิมครบ 5 พื้นที่และ ZIP ผ่านโดยไม่แก้ Preset หรือ content release
