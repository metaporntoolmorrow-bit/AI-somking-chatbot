# เผยแพร่เครื่องมือจริง รุ่น 5

ชุดข้อมูลปัจจุบันคือ real-tools-2026-10-27-v5 ตามการแก้ไขขอบเขตเครื่องมือของเจ้าของโครงการ ดู [ผลแก้ไข](tool-source-correction-v5.md)

แจกเฉพาะไฟล์ในฐานข้อมูลเครื่องมือหลัก/เสริม ปัจจุบันมี 18 เครื่องมือ 30 ไฟล์ เอกสารองค์ประกอบ 4 ฉบับเป็นข้อมูลอ้างอิงภายใน ไม่ใช่เครื่องมือ ไม่เป็นขั้นตอน และไม่รวมใน ZIP คงคำถาม 10 แพ็กเกจ รหัสเส้นทาง 187 รายการ และ 1,983 การเลือกกลุ่มเป้าหมายเดิม บางเส้นทางเหลือเครื่องมือเดียวตามไฟล์จริง

## สร้างและตรวจ Preset

รัน node scripts/build-real-tool-presets.mjs --require-drive --require-public แล้วตรวจ node scripts/test-tool-source-policy.mjs

ตัวสร้างและตัวนำเข้าใช้ src/lib/tool-source-policy.mjs บังคับขอบเขตไฟล์จริง ห้ามเพิ่มเอกสารนอกฐานข้อมูลเป็นเครื่องมือเพียงเพื่อให้มีไฟล์หลายชิ้นหรือดูแตกต่างกัน

CSV ล่าสุดระบุใน presets/real-tools-v1/export-status.json และเอกสารตัวอย่างอยู่ใน chat-preview.md หากไฟล์ CSV ถูกเปิดล็อกอยู่ ใช้ --locked-csv-copy เพื่อส่งออกชื่อรุ่นใหม่โดยไม่ปิดโปรแกรมของผู้ใช้

## นำเข้าฉบับร่างและทดสอบ

ใช้ข้อมูลลับฝั่งเซิร์ฟเวอร์ใน .env.local เท่านั้น ไม่ส่งคีย์ลง GitHub

1. รัน node --env-file=.env.local scripts/release-real-tools.mjs --stage เพื่อนำเข้าฉบับร่าง อัปโหลดไฟล์จริง 10 ไฟล์ และสร้าง ZIP ใหม่ 31 รูปแบบ โดยยังไม่เปลี่ยนข้อมูลที่ผู้ใช้เห็น
2. รัน node scripts/test-tool-source-policy.mjs --bundles เพื่อตรวจทุกไฟล์ใน ZIP รวมถึง hash เทียบกับต้นฉบับและเอกสารที่ต้องไม่แจก
3. รัน node --env-file=.env.local scripts/release-real-tools.mjs --verify
4. สร้างแอป แล้วเปิดทดสอบโดยกำหนด CONTENT_PREVIEW_VERSION=real-tools-2026-10-27-v5 เฉพาะเซิร์ฟเวอร์ในเครื่อง ห้ามตั้งค่านี้บน Production
5. รัน node scripts/test-tool-pdf-layout.mjs เพื่อตรวจ 31 รูปแบบเครื่องมือกับคำแนะนำ 20 ชุด รวม 620 รูปแบบการจัดหน้า แล้วรัน node scripts/test-package-guidance.mjs --smoke, node scripts/test-concept-v3.mjs และ node scripts/test-guidance-downloads.mjs --downloads-only เพื่อทดสอบหน้า Preview แชตบอต PDF และ ZIP จริง การทดสอบคอนเซปต์ตรวจไฟล์เล็กจริงทั้ง 10 ไฟล์และยืนยันว่ารหัส GUIDE เดิมเปิดดาวน์โหลดไม่ได้

หน้า Preview แสดง 3 ส่วนตามภาพอนุมัติ สถานการณ์สรุปจากคำตอบจริง และลำดับเป็นรายการย่อยพร้อมคำอธิบายหนึ่งประโยค ข้อควรระวังและแนวทางใช้ประโยชน์ไม่แสดงใน Preview ตามบรีฟ PDF/ZIP ยังคงข้อมูลตามขอบเขตเดิมและใช้ตัวสร้างคำแนะนำเดียวกัน

## เปิดใช้บนเว็บจริง

เผยแพร่โค้ดที่รองรับเครื่องมือเดียวก่อน แล้วรัน node --env-file=.env.local scripts/release-real-tools.mjs --publish เพื่อสลับ active release เป็นรุ่น 5 ตรวจเว็บจริงอีกครั้งโดยตั้ง TEST_BASE_URL=https://ai-somking-chatbot.vercel.app

ตัวนำเข้าไม่เขียนทับรุ่นที่เผยแพร่แล้ว ไม่ลบไฟล์ต้นฉบับหรือรุ่นเก่า ข้อมูลสำรองสำหรับการกู้คืนอยู่ใน .prd-analysis/real-tools-2026-10-27-v5-release.json และไม่ขึ้น GitHub หากจำเป็นต้องกู้คืนทางเทคนิค ใช้ --rollback แล้วแก้สาเหตุก่อนเปิดใช้รุ่นที่ถูกต้องอีกครั้ง

ไม่เปลี่ยนข้อมูลสมาชิก สิทธิ์ผู้ดูแล ระบบล็อกอิน หรือสิทธิ์ Google Drive ในงานแก้ไขครั้งนี้
