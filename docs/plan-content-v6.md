# นโยบายเนื้อหาแผน รุ่น 6

ตามคำขอเจ้าของโครงการ วันที่ 28 ตุลาคม 2569 ให้ถอน “ข้อควรระวัง” และ “แนวทางการใช้ประโยชน์” ออกจาก Preset และแผน PDF จนกว่าจะมีเนื้อหาจากผู้เชี่ยวชาญ

- ลบคอลัมน์และข้อมูล cautions, benefits, guidanceNote รวมถึงการวนชุดคำแนะนำออกจากต้นทาง ไม่มีการส่งออกเป็นช่องว่างแทน
- PDF คง Artwork เดิม: A4 แนวนอน หัวเรื่องซ้าย บริบทขวา กล่องเครื่องมือเขียว/พีช และคอลัมน์ลำดับสีฟ้า ตัดสองส่วนล่างออกโดยไม่สร้างข้อความทดแทน
- คู่มือเริ่มใช้ใน ZIP ใช้ข้อมูลแผนเดียวกัน จึงตัดสองหัวข้อนี้ออกเช่นกัน ไฟล์เครื่องมือต้นฉบับไม่เปลี่ยนแปลง
- ไม่เผยแพร่คลังคำแนะนำ 200 ชุดหรือไฟล์ Preset สำรองรุ่นเก่าที่มีสองหัวข้อนี้ในชุดไฟล์ปัจจุบัน เก็บสำรองไว้ใน .prd-analysis/catalog-v6/retired และประวัติ Git
- คงคำถาม ตัวเลือก 187 เส้นทาง 1,983 ชุดคำตอบ 10 แพ็กเกจ 18 เครื่องมือ และไฟล์จริง 30 ไฟล์ตามเดิม
- สร้าง ZIP ใหม่ 31 รูปแบบ และนำเข้าเป็น content release ใหม่โดยไม่แก้ข้อมูลสมาชิกหรือระบบล็อกอิน

src/lib/plan-content-policy.mjs ตรวจฟิลด์ที่ต้องไม่ปรากฏทั้งตอนสร้าง Preset และก่อนนำเข้า Supabase การทดสอบตรวจหัวคอลัมน์ CSV, JSON, ข้อความที่สกัดจาก PDF และคู่มือใน ZIP จริง
